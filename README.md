# HomeItemMemo
A simple home inventory tracker for elders and family members, to record where your items, medicine and tools are stored.

✅ No login or registration required
✅ All data is stored locally on your device, never uploaded to server
✅ Support photo and text notes
✅ Free, no ads

📱 Android on Google Play
https://play.google.com/store/apps/details?id=io.github.michaeltsoi.homeitemmemo

🌐 PWA Web Version (Open directly in browser, no installation needed)
https://michael-tsoi.github.io/homeitemmemo/
